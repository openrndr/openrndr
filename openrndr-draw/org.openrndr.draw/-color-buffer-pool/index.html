ColorBufferPool

interface ColorBufferPool(source)

A pool of color buffers, for intermediates that are needed for a short time, such as the passes of a multi-pass filter. acquire hands out a free buffer of the requested size and format or creates one, release gives it back to be handed out again. A pool is not thread safe, it is used from the thread of its share group.

The buffers of a pool are not tracked by a Session, they are destroyed by trim or destroy.

val pool = colorBufferPool()
pool.borrow(width, height, type = ColorType.FLOAT16) { intermediate ->
    horizontal.apply(source, intermediate)
    vertical.apply(intermediate, target)
}
pool.trim(60) // once per frame, destroys buffers that were not acquired in the last 60 frames

abstract fun trim(frames: Int = 0)

Ends a frame of the pool and destroys the free buffers that were not acquired in the last frames frames, all free buffers when frames is 0. A buffer counts as used in the frames it was acquired or released in, buffers that are acquired are kept. Called once per frame it keeps the buffers that are in use from frame to frame.
