GlslFunction

class GlslFunction : DynamicParameter, StyleParameters(source)

A GLSL function with arguments, a GLSL parameter list such as vec2 p, float r, that returns a glslType. code is an expression or a function body with return, it reads its own parameters as p_<name>, which are set on this object and can be dynamic themselves, and can call the functions of libraries. Shade style code calls it as p_<name>(arguments).
