BidiText

interface BidiText(source)

The result of the bidirectional analysis of a text.

The analysis resolves embedding levels for whole paragraphs, reordering happens per line. A typical use is:

  1. shape every run returned by runs using its direction and script

  2. break lines on the shaped runs (in logical order)

  3. call visualRuns for every line to find the order in which the line's runs are displayed

All indices are UTF-16 indices into text, line ranges are half-open (lineEnd is exclusive).

abstract fun visualOrder(lineStart: Int, lineEnd: Int): IntArray

Returns the visual order of the line [lineStart, lineEnd) (rules L1 and L2): element i is the UTF-16 index of the unit displayed at visual position i, from left to right. Surrogate pairs are kept in logical order. Characters are not mirrored, see BidiTextDriver.mirroredCodePoint.

abstract fun visualRuns(lineStart: Int, lineEnd: Int): List<BidiRun>

Returns the runs of the line [lineStart, lineEnd) in visual order, from left to right, with levels after rule L1. The characters of a run with a right-to-left BidiRun.direction are displayed right to left; shaping such a run with Direction.RIGHT_TO_LEFT produces glyphs in visual order.
