OpenTypeMathTable

class OpenTypeMathTable(table: ByteArray, scale: Double) : MathTable(source)

A MathTable read from the bytes of an OpenType MATH table, for drivers whose libraries do not read MATH tables themselves, such as harfbuzzjs. Values in font units are multiplied by scale, the pixels per font unit of the face, the percent constants are given as stored.

Device and variation tables of values are not applied: values are those of the default instance of variable fonts, without adjustments for sizes in pixels.
