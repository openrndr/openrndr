SlugMap

class SlugMap(val curves: ColorBuffer, val bands: ColorBuffer) : BoundaryMap(source)

GPU storage for slug curve and band data.

bands is an integer texture and must use NEAREST filtering; integer textures with LINEAR filtering are incomplete and sample as zero, which makes slug rendering silently draw nothing. NEAREST is set on construction and re-applied by SlugDrawer before drawing.
