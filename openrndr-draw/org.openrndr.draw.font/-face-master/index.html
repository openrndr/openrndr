FaceMaster

data class FaceMaster(val axes: MutableMap<String, Double>, val ranges: Map<String, ClosedFloatingPointRange<Double>>) : MutableMap<String, Double> (source)

Represents the master configuration for a font face, allowing manipulation of axis values within specified ranges for variable font adjustments.

This class acts as a wrapper around a mutable map of axes, providing functionality to enforce valid axis ranges and copy the current instance.
